# Superstore Sales Analytics | Python, SQL & Power BI

An end-to-end sales analytics and business intelligence project using Python, Pandas, SQLite, SQL, Excel and Power BI.

The project demonstrates a complete data analytics workflow, starting from raw sales data and progressing through data processing, database creation, SQL analysis, data modeling, DAX calculations and interactive Power BI dashboards.

---

## 📊 Project Overview

This project analyzes Superstore sales data to identify sales performance patterns across different:

- Regions
- Categories
- Sub-Categories
- Customer Segments
- Order Dates
- Products
- Orders
- Customers

The main objective is to transform raw sales data into meaningful business insights through an end-to-end analytics pipeline.
